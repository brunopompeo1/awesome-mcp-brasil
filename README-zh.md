## 公共数据与政务

IBGE、Banco Central、国会及其他开放数据库。

- [bcb-br-mcp](https://go.mymarketing.click/mcpbr-bcb-br-mcp) - 供智能体使用的 Banco Central 数据：Selic、IPCA、汇率和 PIB。 `开源` `免费`
- [brasil-data-mcp](https://go.mymarketing.click/mcpbr-brasil-data-mcp) - 巴西公共数据集中在一台服务器上：CNPJ、CEP、银行、节假日、DDD、ISBN 和经济指标。 `开源` `免费`
- [cvm-mcp](https://go.mymarketing.click/mcpbr-cvm-mcp) - 面向 CVM 全部开放数据仓库的 MCP 服务器。 `开源` `免费`
- [ibge-br-mcp](https://go.mymarketing.click/mcpbr-ibge-br-mcp) - 供智能体使用的 IBGE API：地理、人口和统计数据。 `开源` `免费`
- [MCP Brasil](https://go.mymarketing.click/mcpbr-mcp-brasil) - 包含 70 个巴西公共 API 的 MCP 服务器。 `开源` `免费`
- [mcp-dados-br](https://go.mymarketing.click/mcpbr-mcp-dados-br) - IBGE、Banco Central、INMET、Câmara 和 Senado 的公共数据。 `开源` `免费`
- [mcp-senado](https://go.mymarketing.click/mcpbr-mcp-senado) - 供智能体使用的 Senado Federal 开放数据：立法、参议员和投票。 `开源` `免费`
- [senado-br-mcp-cloudflare](https://go.mymarketing.click/mcpbr-senado-br-mcp-cloudflare) - 部署在 Cloudflare Workers 上的 Senado Federal 托管 MCP 服务器。 `开源` `免费`

## 企业、CNPJ 与政府采购

查询企业和招投标。

- [Buscador de CNPJ](https://go.mymarketing.click/mcpbr-buscador-de-cnpj) - 通过 Buscador de CNPJ 服务查询企业的 MCP 服务器。 `开源`
- [CNPJ e CEP](https://go.mymarketing.click/mcpbr-cnpj-e-cep) - 远程 MCP 服务器，可按 CNPJ 查询企业，并查询 CEP、节假日、DDD、银行、NCM、Selic、CDI 和 IPCA，还可核验 CPF 和 CNPJ。 `免费` `作者制作`
- [cnpj-mcp](https://go.mymarketing.click/mcpbr-cnpj-mcp) - 基于 DuckDB 对 Receita Federal 开放 CNPJ 数据库进行分析查询。 `开源` `免费`
- [Licinexus MCP](https://go.mymarketing.click/mcpbr-licinexus-mcp) - 供智能体使用的 PNCP 和 Receita Federal 政府采购数据。 `开源`
- [mcp-dadosbr](https://go.mymarketing.click/mcpbr-mcp-dadosbr) - 按 CNPJ 查询企业，按 CEP 查询地址。 `开源` `免费`

## 标签

每项都说明了它是什么。旁边的标签有助于选择：官方表示来自制定标准的一方，开源表示代码已公开，免费或付费指使用模式，API 和 SDK 指集成方式。带有"作者制作"标签的条目由 Ciro Cesar Maciel 制作，并遵循与其他条目相同的规则。
