## Data publik dan pemerintah

IBGE, Banco Central, Kongres, dan basis data terbuka lainnya.

- [bcb-br-mcp](https://go.mymarketing.click/mcpbr-bcb-br-mcp) - Data Banco Central untuk agen: Selic, IPCA, kurs valuta, dan PIB. `open source` `gratis`
- [brasil-data-mcp](https://go.mymarketing.click/mcpbr-brasil-data-mcp) - Data publik Brasil dalam satu server: CNPJ, CEP, bank, hari libur, DDD, ISBN, dan indikator ekonomi. `open source` `gratis`
- [cvm-mcp](https://go.mymarketing.click/mcpbr-cvm-mcp) - Server MCP untuk seluruh repositori data terbuka CVM. `open source` `gratis`
- [ibge-br-mcp](https://go.mymarketing.click/mcpbr-ibge-br-mcp) - API IBGE untuk agen: data geografis, demografis, dan statistik. `open source` `gratis`
- [MCP Brasil](https://go.mymarketing.click/mcpbr-mcp-brasil) - Server MCP dengan 70 API publik Brasil. `open source` `gratis`
- [mcp-dados-br](https://go.mymarketing.click/mcpbr-mcp-dados-br) - Data publik dari IBGE, Banco Central, INMET, Câmara, dan Senado. `open source` `gratis`
- [mcp-senado](https://go.mymarketing.click/mcpbr-mcp-senado) - Data terbuka Senado Federal untuk agen: perundang-undangan, senator, dan pemungutan suara. `open source` `gratis`
- [senado-br-mcp-cloudflare](https://go.mymarketing.click/mcpbr-senado-br-mcp-cloudflare) - Server MCP Senado Federal yang di-hosting di Cloudflare Workers. `open source` `gratis`

## Perusahaan, CNPJ, dan pengadaan publik

Cari perusahaan dan tender.

- [Buscador de CNPJ](https://go.mymarketing.click/mcpbr-buscador-de-cnpj) - Server MCP untuk mencari perusahaan lewat layanan Buscador de CNPJ. `open source`
- [CNPJ e CEP](https://go.mymarketing.click/mcpbr-cnpj-e-cep) - Server MCP jarak jauh untuk data perusahaan berdasarkan CNPJ, CEP, hari libur, DDD, bank, NCM, Selic, CDI, dan IPCA, serta pengecekan CPF dan CNPJ. `gratis` `buatan penulis`
- [cnpj-mcp](https://go.mymarketing.click/mcpbr-cnpj-mcp) - Kueri analitis atas basis data terbuka CNPJ Receita Federal, dengan DuckDB. `open source` `gratis`
- [Licinexus MCP](https://go.mymarketing.click/mcpbr-licinexus-mcp) - Data pengadaan publik dari PNCP dan Receita Federal untuk agen. `open source`
- [mcp-dadosbr](https://go.mymarketing.click/mcpbr-mcp-dadosbr) - Cek perusahaan berdasarkan CNPJ dan alamat berdasarkan CEP. `open source` `gratis`
- [Radar CNPJ MCP](https://go.mymarketing.click/mcpbr-radar-cnpj-mcp) - Mencari perusahaan Brasil berdasarkan CNAE dan wilayah, dengan data terbuka Receita Federal. `open source` `gratis`

## Pajak dan dokumen fiskal

Pajak, dokumen fiskal, dan kewajiban.

- [MCP Fiscal Brasil](https://go.mymarketing.click/mcpbr-mcp-fiscal-brasil) - Server MCP fiskal: CNPJ, NF-e, NFS-e, CT-e, SPED, eSocial, Simples Nacional, dan reformasi pajak. `open source` `gratis`
- [MCP Server ACBrNFe](https://go.mymarketing.click/mcpbr-mcp-server-acbrnfe) - Pembuatan dan pengiriman NF-e dengan komponen ACBrNFe, di Delphi. `open source` `gratis`

## Hukum dan perundang-undangan

Undang-undang, perkara, dan preseden.

- [BNP API](https://go.mymarketing.click/mcpbr-bnp-api) - Server MCP untuk Banco Nacional de Precedentes CNJ, dengan pencarian preseden yang mengikat. `open source` `gratis`
- [br-eli-mcp](https://go.mymarketing.click/mcpbr-br-eli-mcp) - Perundang-undangan Brasil lewat delapan API terbuka tanpa kunci: RUU dan undang-undang dari Câmara dan Senado, DataJud, dan lainnya. `open source` `gratis`
- [brlaw_mcp_server](https://go.mymarketing.click/mcpbr-brlaw-mcp-server) - Riset hukum Brasil dari sumber resmi, dilakukan oleh agen. `open source` `gratis`
- [leis-mcp](https://go.mymarketing.click/mcpbr-leis-mcp) - Mencari dan mengutip perundang-undangan Brasil di Claude dan asisten lain. `open source` `gratis`
- [MCP Jurídico Brasil](https://go.mymarketing.click/mcpbr-mcp-juridico-brasil) - Platform hukum modular berbasis MCP, dimulai dari pemantauan perkara. `open source` `gratis`

## Pasar keuangan

Bursa, dana, dan keuangan terbuka.

- [bolsai-mcp](https://go.mymarketing.click/mcpbr-bolsai-mcp) - Data pasar saham Brasil (B3, CVM, dan Banco Central) untuk agen. `open source`
- [DataBolsa](https://go.mymarketing.click/mcpbr-databolsa) - SDK TypeScript, CLI, dan server MCP untuk API data bursa Brasil DataBolsa. `open source` `SDK`
- [local-openfinance](https://go.mymarketing.click/mcpbr-local-openfinance) - Menyinkronkan data Open Finance Brasil ke SQLite lokal untuk mencatat pengeluaran dan membuat laporan. `open source` `gratis`
- [OpenFinData](https://go.mymarketing.click/mcpbr-openfindata) - Infrastruktur terbuka untuk data keuangan publik Brasil. `open source` `gratis`

## Agribisnis

Kutipan dan data pertanian.

- [agrobr-mcp](https://go.mymarketing.click/mcpbr-agrobr-mcp) - Data pertanian Brasil: harga, panen, perdagangan, iklim, dan deforestasi. `open source` `gratis`
- [MCP Agro Brasil](https://go.mymarketing.click/mcpbr-mcp-agro-brasil) - Kutipan agribisnis (sapi, kedelai, jagung, susu) dan konversi satuan. `open source` `gratis`

- [hotmart-mcp](https://go.mymarketing.click/mcpbr-hotmart-mcp) - Server MCP untuk API Hotmart: penjualan, langganan, klub, produk, dan kupon. `open source` `gratis`
- [Mercado Pago MCP Server](https://go.mymarketing.click/mcpbr-mercado-pago-mcp-server) - Server MCP resmi dari Mercado Pago untuk membaca dokumentasi dan mengintegrasikan pembayaran melalui agen. `resmi`
- [mcp-woovi-api](https://go.mymarketing.click/mcpbr-mcp-woovi-api) - Server MCP untuk API Woovi dan OpenPix, untuk tagihan Pix. `open source` `gratis`

## ERP dan manajemen

Sistem manajemen yang paling banyak digunakan perusahaan Brasil.

- [bling-erp-mcp-server](https://go.mymarketing.click/mcpbr-bling-erp-mcp-server) - Server MCP tidak resmi untuk Bling ERP. `open source` `gratis`
- [Conta Azul MCP](https://go.mymarketing.click/mcpbr-conta-azul-mcp) - Menghubungkan ERP Conta Azul ke Claude, Cursor, dan agen lain: penjualan, pelanggan, dan produk. `open source` `gratis`
- [olist-mcp-server](https://go.mymarketing.click/mcpbr-olist-mcp-server) - Server MCP untuk API v3 Olist ERP (Tiny), dengan alat yang dibuat dari spesifikasi OpenAPI. `open source` `gratis`

## Koleksi dan ekosistem

Proyek yang mengumpulkan banyak konektor Brasil.

- [BridgeAPI](https://go.mymarketing.click/mcpbr-bridgeapi) - Ekosistem konektor MCP untuk platform Brasil, seperti WhatsApp dan Hotmart. `open source`
- [Connectors (Agents)](https://go.mymarketing.click/mcpbr-connectors-agents) - Katalog server MCP jarak jauh dengan OAuth, termasuk CNPJ, CEP, dan Hotmart, untuk Claude, Cursor, dan klien lainnya. `buatan penulis`

## Label

Setiap item menjelaskan apa itu. Label di sebelahnya membantu memilih: resmi jika berasal dari pihak yang menetapkan standar, open source jika kodenya dipublikasikan, gratis atau berbayar menurut model penggunaannya, API dan SDK menurut cara integrasinya. Item dengan label "buatan penulis" dibuat oleh Ciro Cesar Maciel dan mengikuti aturan yang sama dengan item lainnya.
