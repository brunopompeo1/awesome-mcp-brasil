Para quien quiera que Claude, Cursor u otro agente de IA consulte y opere servicios de Brasil mediante Model Context Protocol. Cada elemento es un servidor MCP que existe hoy, con el código o la documentación publicados. Los proyectos de la comunidad no son oficiales, salvo que la etiqueta lo indique.

## Etiquetas

Cada elemento indica qué es. Las etiquetas ayudan a elegir: oficial cuando viene de quien define el estándar, código abierto cuando el código está publicado, gratis o de pago según el modelo de uso, API y SDK según la forma de integrar. Los elementos con la etiqueta "del autor" son hechos por Ciro Cesar Maciel y siguen las mismas reglas que todos los demás.
