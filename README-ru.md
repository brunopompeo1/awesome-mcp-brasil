## Открытые данные и государство

IBGE, Banco Central, Congresso и другие открытые базы.

- [brasil-data-mcp](https://go.mymarketing.click/mcpbr-brasil-data-mcp) - Бразильские открытые данные на одном сервере: CNPJ, CEP, банки, праздники, DDD, ISBN и экономические показатели. `открытый код` `бесплатный`
- [cvm-mcp](https://go.mymarketing.click/mcpbr-cvm-mcp) - MCP-сервер для всего открытого репозитория данных CVM. `открытый код` `бесплатный`
- [ibge-br-mcp](https://go.mymarketing.click/mcpbr-ibge-br-mcp) - API IBGE для агентов: географические, демографические и статистические данные. `открытый код` `бесплатный`
- [MCP Brasil](https://go.mymarketing.click/mcpbr-mcp-brasil) - MCP-сервер с 70 публичными бразильскими API. `открытый код` `бесплатный`
- [mcp-dados-br](https://go.mymarketing.click/mcpbr-mcp-dados-br) - Открытые данные IBGE, Banco Central, INMET, Câmara и Senado. `открытый код` `бесплатный`
- [mcp-senado](https://go.mymarketing.click/mcpbr-mcp-senado) - Открытые данные Senado Federal для агентов: законодательство, сенаторы и голосования. `открытый код` `бесплатный`

## Метки

У каждого пункта есть описание. Метки помогают выбрать: официальный — когда сделано тем, кто задаёт стандарт; открытый код — когда код опубликован; бесплатный или платный — по модели использования; API и SDK — по способу интеграции. Пункты с меткой «от автора» сделаны Сиро Сесаром Масиэлом и подчиняются тем же правилам, что и все остальные.
