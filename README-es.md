Para quien quiera que Claude, Cursor u otro agente de IA consulte y opere servicios de Brasil mediante Model Context Protocol. Cada elemento es un servidor MCP que existe hoy, con el código o la documentación publicados. Los proyectos de la comunidad no son oficiales, salvo que la etiqueta lo indique.

## Datos públicos y gobierno

IBGE, Banco Central, Congreso y otras bases abiertas.

- [bcb-br-mcp](https://go.mymarketing.click/mcpbr-bcb-br-mcp) - Datos del Banco Central para agentes: Selic, IPCA, tipo de cambio y PIB. `código abierto` `gratis`
- [brasil-data-mcp](https://go.mymarketing.click/mcpbr-brasil-data-mcp) - Datos públicos brasileños en un solo servidor: CNPJ, CEP, bancos, feriados, DDD, ISBN e indicadores económicos. `código abierto` `gratis`
- [cvm-mcp](https://go.mymarketing.click/mcpbr-cvm-mcp) - Un servidor MCP para todo el repositorio de datos abiertos de la CVM. `código abierto` `gratis`
- [ibge-br-mcp](https://go.mymarketing.click/mcpbr-ibge-br-mcp) - Las APIs del IBGE para agentes: datos geográficos, demográficos y estadísticos. `código abierto` `gratis`
- [MCP Brasil](https://go.mymarketing.click/mcpbr-mcp-brasil) - Servidor MCP con 70 APIs públicas brasileñas. `código abierto` `gratis`
- [mcp-dados-br](https://go.mymarketing.click/mcpbr-mcp-dados-br) - Datos públicos del IBGE, del Banco Central, del INMET, de la Cámara y del Senado. `código abierto` `gratis`
- [mcp-senado](https://go.mymarketing.click/mcpbr-mcp-senado) - Los datos abiertos del Senado Federal para agentes: legislación, senadores y votaciones. `código abierto` `gratis`
- [senado-br-mcp-cloudflare](https://go.mymarketing.click/mcpbr-senado-br-mcp-cloudflare) - Servidor MCP alojado del Senado Federal, en Cloudflare Workers. `código abierto` `gratis`

- [Licinexus MCP](https://go.mymarketing.click/mcpbr-licinexus-mcp) - Datos de compras públicas del PNCP y de la Receita Federal para agentes. `código abierto`
- [mcp-dadosbr](https://go.mymarketing.click/mcpbr-mcp-dadosbr) - Consulta de empresa por CNPJ y de dirección por CEP. `código abierto` `gratis`
- [Radar CNPJ MCP](https://go.mymarketing.click/mcpbr-radar-cnpj-mcp) - Encuentra empresas brasileñas por CNAE y región, con datos abiertos de la Receita Federal. `código abierto` `gratis`

Proyectos que reúnen varios conectores brasileños.

- [BridgeAPI](https://go.mymarketing.click/mcpbr-bridgeapi) - Un ecosistema de conectores MCP para plataformas brasileñas, como WhatsApp y Hotmart. `código abierto`
- [Connectors (Agents)](https://go.mymarketing.click/mcpbr-connectors-agents) - Catálogo de servidores MCP remotos con OAuth, entre ellos CNPJ, CEP y Hotmart, para Claude, Cursor y otros clientes. `del autor`

## Etiquetas

Cada elemento indica qué es. Las etiquetas ayudan a elegir: oficial cuando viene de quien define el estándar, código abierto cuando el código está publicado, gratis o de pago según el modelo de uso, API y SDK según la forma de integrar. Los elementos con la etiqueta "del autor" son hechos por Ciro Cesar Maciel y siguen las mismas reglas que todos los demás.
