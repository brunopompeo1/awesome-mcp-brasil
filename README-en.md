## Public data and government

IBGE, Banco Central, Congresso and other open databases.

- [bcb-br-mcp](https://go.mymarketing.click/mcpbr-bcb-br-mcp) - Banco Central data for agents: Selic, IPCA, exchange rates and GDP. `open source` `free`
- [brasil-data-mcp](https://go.mymarketing.click/mcpbr-brasil-data-mcp) - Brazilian public data in a single server: CNPJ, CEP, banks, holidays, DDD, ISBN and economic indicators. `open source` `free`
- [cvm-mcp](https://go.mymarketing.click/mcpbr-cvm-mcp) - An MCP server for CVM's entire open data repository. `open source` `free`
- [ibge-br-mcp](https://go.mymarketing.click/mcpbr-ibge-br-mcp) - IBGE APIs for agents: geographic, demographic and statistical data. `open source` `free`
- [MCP Brasil](https://go.mymarketing.click/mcpbr-mcp-brasil) - MCP server with 70 public Brazilian APIs. `open source` `free`
- [mcp-dados-br](https://go.mymarketing.click/mcpbr-mcp-dados-br) - Public data from IBGE, Banco Central, INMET, Câmara and Senado. `open source` `free`
- [mcp-senado](https://go.mymarketing.click/mcpbr-mcp-senado) - Senado Federal open data for agents: legislation, senators and votes. `open source` `free`
- [senado-br-mcp-cloudflare](https://go.mymarketing.click/mcpbr-senado-br-mcp-cloudflare) - Hosted MCP server for Senado Federal, on Cloudflare Workers. `open source` `free`

## Companies, CNPJ and public procurement

Look up companies and public tenders.

- [Buscador de CNPJ](https://go.mymarketing.click/mcpbr-buscador-de-cnpj) - MCP server to look up companies through the Buscador de CNPJ service. `open source`
- [CNPJ e CEP](https://go.mymarketing.click/mcpbr-cnpj-e-cep) - Remote MCP server with company lookup by CNPJ, CEP, holidays, DDD, banks, NCM, Selic, CDI and IPCA, and CPF and CNPJ validation. `free` `by the author`
- [cnpj-mcp](https://go.mymarketing.click/mcpbr-cnpj-mcp) - Analytical queries over Receita Federal's open CNPJ database, with DuckDB. `open source` `free`
- [Licinexus MCP](https://go.mymarketing.click/mcpbr-licinexus-mcp) - Public procurement data from PNCP and Receita Federal for agents. `open source`
- [mcp-dadosbr](https://go.mymarketing.click/mcpbr-mcp-dadosbr) - Company lookup by CNPJ and address lookup by CEP. `open source` `free`
- [Radar CNPJ MCP](https://go.mymarketing.click/mcpbr-radar-cnpj-mcp) - Finds Brazilian companies by CNAE and region, using Receita Federal open data. `open source` `free`

## Tax and invoices

Taxes, tax documents and obligations.

- [MCP Fiscal Brasil](https://go.mymarketing.click/mcpbr-mcp-fiscal-brasil) - Tax MCP server: CNPJ, NF-e, NFS-e, CT-e, SPED, eSocial, Simples Nacional and the tax reform. `open source` `free`
- [MCP Server ACBrNFe](https://go.mymarketing.click/mcpbr-mcp-server-acbrnfe) - Generate and send NF-e with the ACBrNFe component, in Delphi. `open source` `free`

## Legal and legislation

Laws, cases and precedents.

- [BNP API](https://go.mymarketing.click/mcpbr-bnp-api) - MCP server for CNJ's National Precedents Bank, with search for binding precedents. `open source` `free`
- [br-eli-mcp](https://go.mymarketing.click/mcpbr-br-eli-mcp) - Brazilian legislation through eight open APIs with no key: bills and laws from Câmara and Senado, DataJud and others. `open source` `free`
- [brlaw_mcp_server](https://go.mymarketing.click/mcpbr-brlaw-mcp-server) - Research on Brazilian law from official sources, done by agents. `open source` `free`
- [leis-mcp](https://go.mymarketing.click/mcpbr-leis-mcp) - Searches and cites Brazilian legislation in Claude and other assistants. `open source` `free`
- [MCP Jurídico Brasil](https://go.mymarketing.click/mcpbr-mcp-juridico-brasil) - Modular legal platform via MCP, starting with case tracking. `open source` `free`

## Financial market

Stock exchange, funds and open finance.

- [bolsai-mcp](https://go.mymarketing.click/mcpbr-bolsai-mcp) - Brazilian stock market data (B3, CVM and Banco Central) for agents. `open source`
- [DataBolsa](https://go.mymarketing.click/mcpbr-databolsa) - TypeScript SDK, CLI and MCP server for the DataBolsa Brazilian stock exchange data API. `open source` `SDK`
- [local-openfinance](https://go.mymarketing.click/mcpbr-local-openfinance) - Syncs Brazilian Open Finance data into a local SQLite to track spending and generate reports. `open source` `free`
- [OpenFinData](https://go.mymarketing.click/mcpbr-openfindata) - Open infrastructure for public financial data in Brazil. `open source` `free`

## Agribusiness

Quotes and farm data.

- [agrobr-mcp](https://go.mymarketing.click/mcpbr-agrobr-mcp) - Brazilian agricultural data: prices, harvests, trade, climate and deforestation. `open source` `free`
- [MCP Agro Brasil](https://go.mymarketing.click/mcpbr-mcp-agro-brasil) - Agribusiness quotes (cattle, soybean, corn, milk) and unit conversions. `open source` `free`

## Digital payments and sales

Charge, collect and track sales.

- [Hotmart](https://go.mymarketing.click/mcpbr-hotmart) - Remote MCP server with Hotmart sales, subscriptions and affiliate commissions; refunds only with approval. `by the author`
- [hotmart-mcp](https://go.mymarketing.click/mcpbr-hotmart-mcp) - MCP server for the Hotmart API: sales, subscriptions, club, products and coupons. `open source` `free`
- [Mercado Pago MCP Server](https://go.mymarketing.click/mcpbr-mercado-pago-mcp-server) - The official Mercado Pago MCP server, to look up the documentation and integrate payments through the agent. `official`
- [mcp-woovi-api](https://go.mymarketing.click/mcpbr-mcp-woovi-api) - MCP server for the Woovi and OpenPix API, for Pix charges. `open source` `free`

## E-commerce and marketplaces

Stores, marketplaces and commerce in Latin America.

- [MCP Dev LATAM](https://go.mymarketing.click/mcpbr-mcp-dev-latam) - MCP servers for commerce in Latin America: Pix, NF-e, banks, tax, logistics and messaging. `open source` `free`
- [mcp-mercado-livre](https://go.mymarketing.click/mcpbr-mcp-mercado-livre) - MCP server to interact with the Mercado Livre API. `open source` `free`
- [nuvemshop-mcp-server](https://go.mymarketing.click/mcpbr-nuvemshop-mcp-server) - MCP server for the Nuvemshop API: products, orders and customers. `open source` `free`

## ERPs and management

The management systems most used by Brazilian companies.

- [bling-erp-mcp-server](https://go.mymarketing.click/mcpbr-bling-erp-mcp-server) - Unofficial MCP server for Bling ERP. `open source` `free`
- [Conta Azul MCP](https://go.mymarketing.click/mcpbr-conta-azul-mcp) - Connects the Conta Azul ERP to Claude, Cursor and agents: sales, customers and products. `open source` `free`
- [olist-mcp-server](https://go.mymarketing.click/mcpbr-olist-mcp-server) - MCP server for the Olist ERP (Tiny) API v3, with tools generated from the OpenAPI specification. `open source` `free`

## Collections and ecosystems

Projects that gather several Brazilian connectors.

- [BridgeAPI](https://go.mymarketing.click/mcpbr-bridgeapi) - An ecosystem of MCP connectors for Brazilian platforms, such as WhatsApp and Hotmart. `open source`
- [Connectors (Agents)](https://go.mymarketing.click/mcpbr-connectors-agents) - Catalog of remote MCP servers with OAuth, including CNPJ, CEP and Hotmart, for Claude, Cursor and other clients. `by the author`

## Tags

Each item says what it is. The tags next to it help you choose: official when it comes from the party that defines the standard, open source when the code is published, free or paid based on the usage model, API and SDK based on how you integrate. Items tagged "by the author" are made by Ciro Cesar Maciel and follow the same rules as all the others.
