Per chi vuole che Claude, Cursor o un altro agente di IA consulti e usi i servizi del Brasile tramite il Model Context Protocol. Ogni voce è un server MCP esistente oggi, con codice o documentazione pubblicati. I progetti della comunità non sono ufficiali, a meno che l'etichetta non lo indichi.

## Dati pubblici e governo

IBGE, Banco Central, Congresso e altre basi aperte.

- [bcb-br-mcp](https://go.mymarketing.click/mcpbr-bcb-br-mcp) - Dati della Banco Central per agenti: Selic, IPCA, cambio e PIL. `open source` `gratis`
- [brasil-data-mcp](https://go.mymarketing.click/mcpbr-brasil-data-mcp) - Dati pubblici brasiliani su un unico server: CNPJ, CEP, banche, festività, DDD, ISBN e indicatori economici. `open source` `gratis`
- [cvm-mcp](https://go.mymarketing.click/mcpbr-cvm-mcp) - Un server MCP per l'intero repository di dati aperti della CVM. `open source` `gratis`
- [ibge-br-mcp](https://go.mymarketing.click/mcpbr-ibge-br-mcp) - Le API dell'IBGE per agenti: dati geografici, demografici e statistici. `open source` `gratis`
- [MCP Brasil](https://go.mymarketing.click/mcpbr-mcp-brasil) - Server MCP con 70 API pubbliche brasiliane. `open source` `gratis`
- [mcp-dados-br](https://go.mymarketing.click/mcpbr-mcp-dados-br) - Dati pubblici dell'IBGE, della Banco Central, dell'INMET, della Câmara e del Senado. `open source` `gratis`
- [mcp-senado](https://go.mymarketing.click/mcpbr-mcp-senado) - I dati aperti del Senado Federal per agenti: legislazione, senatori e votazioni. `open source` `gratis`
- [senado-br-mcp-cloudflare](https://go.mymarketing.click/mcpbr-senado-br-mcp-cloudflare) - Server MCP ospitato del Senado Federal, su Cloudflare Workers. `open source` `gratis`

## Aziende, CNPJ e appalti pubblici

Consultare aziende e gare.

- [Buscador de CNPJ](https://go.mymarketing.click/mcpbr-buscador-de-cnpj) - Server MCP per consultare aziende tramite il servizio Buscador de CNPJ. `open source`
- [CNPJ e CEP](https://go.mymarketing.click/mcpbr-cnpj-e-cep) - Server MCP remoto con azienda tramite CNPJ, CEP, festività, DDD, banche, NCM, Selic, CDI e IPCA, e verifica di CPF e CNPJ. `gratis` `dell'autore`
- [cnpj-mcp](https://go.mymarketing.click/mcpbr-cnpj-mcp) - Interrogazioni analitiche sulla base aperta CNPJ della Receita Federal, con DuckDB. `open source` `gratis`
- [Licinexus MCP](https://go.mymarketing.click/mcpbr-licinexus-mcp) - Dati sugli appalti pubblici del PNCP e della Receita Federal per agenti. `open source`
- [mcp-dadosbr](https://go.mymarketing.click/mcpbr-mcp-dadosbr) - Consultazione di un'azienda tramite CNPJ e di un indirizzo tramite CEP. `open source` `gratis`
- [Radar CNPJ MCP](https://go.mymarketing.click/mcpbr-radar-cnpj-mcp) - Trova aziende brasiliane per CNAE e regione, con dati aperti della Receita Federal. `open source` `gratis`

## Fiscale e fattura

Tasse, documenti fiscali e obblighi.

- [MCP Fiscal Brasil](https://go.mymarketing.click/mcpbr-mcp-fiscal-brasil) - Server MCP fiscale: CNPJ, NF-e, NFS-e, CT-e, SPED, eSocial, Simples Nacional e la riforma fiscale. `open source` `gratis`
- [MCP Server ACBrNFe](https://go.mymarketing.click/mcpbr-mcp-server-acbrnfe) - Generazione e invio di NF-e con il componente ACBrNFe, in Delphi. `open source` `gratis`

## Giuridico e legislazione

Leggi, processi e precedenti.

- [BNP API](https://go.mymarketing.click/mcpbr-bnp-api) - Server MCP per il Banco Nacional de Precedentes del CNJ, con ricerca di precedenti vincolanti. `open source` `gratis`
- [br-eli-mcp](https://go.mymarketing.click/mcpbr-br-eli-mcp) - Legislazione brasiliana tramite otto API aperte senza chiave: progetti e leggi della Câmara e del Senado, DataJud e altre. `open source` `gratis`
- [brlaw_mcp_server](https://go.mymarketing.click/mcpbr-brlaw-mcp-server) - Ricerca sul diritto brasiliano in fonti ufficiali, svolta da agenti. `open source` `gratis`
- [leis-mcp](https://go.mymarketing.click/mcpbr-leis-mcp) - Cerca e cita la legislazione brasiliana in Claude e in altri assistenti. `open source` `gratis`
- [MCP Jurídico Brasil](https://go.mymarketing.click/mcpbr-mcp-juridico-brasil) - Piattaforma giuridica modulare via MCP, che parte dal monitoraggio dei processi. `open source` `gratis`

## Mercato finanziario

Borsa, fondi e finanza aperta.

- [bolsai-mcp](https://go.mymarketing.click/mcpbr-bolsai-mcp) - Dati del mercato azionario brasiliano (B3, CVM e Banco Central) per agenti. `open source`
- [DataBolsa](https://go.mymarketing.click/mcpbr-databolsa) - SDK in TypeScript, CLI e server MCP per l'API dei dati della borsa brasiliana di DataBolsa. `open source` `SDK`
- [local-openfinance](https://go.mymarketing.click/mcpbr-local-openfinance) - Sincronizza i dati dell'Open Finance brasiliano in un SQLite locale per annotare le spese e generare report. `open source` `gratis`
- [OpenFinData](https://go.mymarketing.click/mcpbr-openfindata) - Infrastruttura aperta per i dati finanziari pubblici del Brasile. `open source` `gratis`

## Agroindustria

Quotazioni e dati dei campi.

- [agrobr-mcp](https://go.mymarketing.click/mcpbr-agrobr-mcp) - Dati agricoli brasiliani: prezzi, raccolti, commercio, clima e deforestazione. `open source` `gratis`
- [MCP Agro Brasil](https://go.mymarketing.click/mcpbr-mcp-agro-brasil) - Quotazioni dell'agroindustria (bovini, soia, mais, latte) e conversioni di unità. `open source` `gratis`

## Pagamenti e vendite digitali

Addebitare, incassare e monitorare le vendite.

- [Hotmart](https://go.mymarketing.click/mcpbr-hotmart) - Server MCP remoto con vendite, abbonamenti e commissioni di affiliazione di Hotmart; rimborso solo con approvazione. `dell'autore`
- [hotmart-mcp](https://go.mymarketing.click/mcpbr-hotmart-mcp) - Server MCP per l'API di Hotmart: vendite, abbonamenti, club, prodotti e coupon. `open source` `gratis`
- [Mercado Pago MCP Server](https://go.mymarketing.click/mcpbr-mercado-pago-mcp-server) - Il server MCP ufficiale di Mercado Pago, per consultare la documentazione e integrare i pagamenti tramite l'agente. `ufficiale`
- [mcp-woovi-api](https://go.mymarketing.click/mcpbr-mcp-woovi-api) - Server MCP per l'API di Woovi e OpenPix, per addebiti via Pix. `open source` `gratis`

Negozi, marketplace e commercio dell'America Latina.

- [MCP Dev LATAM](https://go.mymarketing.click/mcpbr-mcp-dev-latam) - Server MCP per il commercio in America Latina: Pix, NF-e, banche, fiscale, logistica e messaggistica. `open source` `gratis`
- [mcp-mercado-livre](https://go.mymarketing.click/mcpbr-mcp-mercado-livre) - Server MCP per interagire con l'API di Mercado Livre. `open source` `gratis`
- [nuvemshop-mcp-server](https://go.mymarketing.click/mcpbr-nuvemshop-mcp-server) - Server MCP per l'API di Nuvemshop: prodotti, ordini e clienti. `open source` `gratis`

## ERP e gestionale

I sistemi di gestione più usati dalle aziende brasiliane.

- [bling-erp-mcp-server](https://go.mymarketing.click/mcpbr-bling-erp-mcp-server) - Server MCP non ufficiale per Bling ERP. `open source` `gratis`
- [Conta Azul MCP](https://go.mymarketing.click/mcpbr-conta-azul-mcp) - Collega l'ERP Conta Azul a Claude, Cursor e agenti: vendite, clienti e prodotti. `open source` `gratis`
- [olist-mcp-server](https://go.mymarketing.click/mcpbr-olist-mcp-server) - Server MCP per l'API v3 di Olist ERP (Tiny), con strumenti generati dalla specifica OpenAPI. `open source` `gratis`

## Raccolte ed ecosistemi

Progetti che raccolgono diversi connettori brasiliani.

- [BridgeAPI](https://go.mymarketing.click/mcpbr-bridgeapi) - Un ecosistema di connettori MCP per piattaforme brasiliane, come WhatsApp e Hotmart. `open source`
- [Connectors (Agents)](https://go.mymarketing.click/mcpbr-connectors-agents) - Catalogo di server MCP remoti con OAuth, tra cui CNPJ, CEP e Hotmart, per Claude, Cursor e altri client. `dell'autore`

## Etichette

Ogni voce spiega cosa è. Le etichette accanto aiutano a scegliere: ufficiale quando viene da chi definisce lo standard, open source quando il codice è pubblicato, gratis o a pagamento in base al modello d'uso, API e SDK in base al modo di integrare. Le voci con l'etichetta "dell'autore" sono realizzate da Ciro Cesar Maciel e seguono le stesse regole di tutte le altre.
