## 태그

각 항목은 무엇인지 설명합니다. 옆의 태그는 선택에 도움을 줍니다. 공식은 표준을 정한 곳에서 제공할 때, 오픈 소스는 코드가 공개되어 있을 때, 무료와 유료는 이용 방식 기준, API와 SDK는 연동 방식 기준입니다. “do autor” 태그가 붙은 항목은 Ciro Cesar Maciel이 만들었으며 다른 모든 항목과 같은 규칙을 따릅니다.
