## Dados públicos e governo

IBGE, Banco Central, Congresso e outras bases abertas.

- [bcb-br-mcp](https://go.mymarketing.click/mcpbr-bcb-br-mcp) - Dados do Banco Central para agentes: Selic, IPCA, câmbio e PIB. `código aberto` `grátis`
- [brasil-data-mcp](https://go.mymarketing.click/mcpbr-brasil-data-mcp) - Dados públicos brasileiros num servidor só: CNPJ, CEP, bancos, feriados, DDD, ISBN e indicadores econômicos. `código aberto` `grátis`
- [cvm-mcp](https://go.mymarketing.click/mcpbr-cvm-mcp) - Um servidor MCP para o repositório de dados abertos da CVM inteiro. `código aberto` `grátis`
- [ibge-br-mcp](https://go.mymarketing.click/mcpbr-ibge-br-mcp) - As APIs do IBGE para agentes: dados geográficos, demográficos e estatísticos. `código aberto` `grátis`
- [MCP Brasil](https://go.mymarketing.click/mcpbr-mcp-brasil) - Servidor MCP com 70 APIs públicas brasileiras. `código aberto` `grátis`
- [mcp-dados-br](https://go.mymarketing.click/mcpbr-mcp-dados-br) - Dados públicos do IBGE, do Banco Central, do INMET, da Câmara e do Senado. `código aberto` `grátis`
- [mcp-senado](https://go.mymarketing.click/mcpbr-mcp-senado) - Os dados abertos do Senado Federal para agentes: legislação, senadores e votações. `código aberto` `grátis`
- [senado-br-mcp-cloudflare](https://go.mymarketing.click/mcpbr-senado-br-mcp-cloudflare) - Servidor MCP hospedado do Senado Federal, no Cloudflare Workers. `código aberto` `grátis`

## Empresas, CNPJ e compras públicas

Consultar empresas e licitações.

- [Buscador de CNPJ](https://go.mymarketing.click/mcpbr-buscador-de-cnpj) - Servidor MCP para consultar empresas pelo serviço Buscador de CNPJ. `código aberto`
- [CNPJ e CEP](https://go.mymarketing.click/mcpbr-cnpj-e-cep) - Servidor MCP remoto com empresa pelo CNPJ, CEP, feriados, DDD, bancos, NCM, Selic, CDI e IPCA, e conferência de CPF e CNPJ. `grátis` `do autor`
- [cnpj-mcp](https://go.mymarketing.click/mcpbr-cnpj-mcp) - Consultas analíticas sobre a base aberta de CNPJ da Receita Federal, com DuckDB. `código aberto` `grátis`
- [Licinexus MCP](https://go.mymarketing.click/mcpbr-licinexus-mcp) - Dados de compras públicas do PNCP e da Receita Federal para agentes. `código aberto`
- [mcp-dadosbr](https://go.mymarketing.click/mcpbr-mcp-dadosbr) - Consulta de empresa pelo CNPJ e de endereço pelo CEP. `código aberto` `grátis`
- [Radar CNPJ MCP](https://go.mymarketing.click/mcpbr-radar-cnpj-mcp) - Encontra empresas brasileiras por CNAE e região, com dados abertos da Receita Federal. `código aberto` `grátis`

## Jurídico e legislação

Leis, processos e precedentes.

- [BNP API](https://go.mymarketing.click/mcpbr-bnp-api) - Servidor MCP para o Banco Nacional de Precedentes do CNJ, com busca de precedentes vinculantes. `código aberto` `grátis`
- [br-eli-mcp](https://go.mymarketing.click/mcpbr-br-eli-mcp) - Legislação brasileira por oito APIs abertas sem chave: projetos e leis da Câmara e do Senado, DataJud e outras. `código aberto` `grátis`
- [brlaw_mcp_server](https://go.mymarketing.click/mcpbr-brlaw-mcp-server) - Pesquisa sobre o direito brasileiro em fontes oficiais, feita por agentes. `código aberto` `grátis`
- [leis-mcp](https://go.mymarketing.click/mcpbr-leis-mcp) - Busca e cita a legislação brasileira no Claude e em outros assistentes. `código aberto` `grátis`
- [MCP Jurídico Brasil](https://go.mymarketing.click/mcpbr-mcp-juridico-brasil) - Plataforma jurídica modular por MCP, começando pelo acompanhamento processual. `código aberto` `grátis`

## Mercado financeiro

Bolsa, fundos e finanças abertas.

- [bolsai-mcp](https://go.mymarketing.click/mcpbr-bolsai-mcp) - Dados do mercado de ações brasileiro (B3, CVM e Banco Central) para agentes. `código aberto`
- [DataBolsa](https://go.mymarketing.click/mcpbr-databolsa) - SDK em TypeScript, CLI e servidor MCP para a API de dados da bolsa brasileira do DataBolsa. `código aberto` `SDK`
- [local-openfinance](https://go.mymarketing.click/mcpbr-local-openfinance) - Sincroniza dados do Open Finance brasileiro num SQLite local para anotar gastos e gerar relatórios. `código aberto` `grátis`
- [OpenFinData](https://go.mymarketing.click/mcpbr-openfindata) - Infraestrutura aberta para dados financeiros públicos do Brasil. `código aberto` `grátis`

## Coleções e ecossistemas

Projetos que reúnem vários conectores brasileiros.

- [BridgeAPI](https://go.mymarketing.click/mcpbr-bridgeapi) - Um ecossistema de conectores MCP para plataformas brasileiras, como WhatsApp e Hotmart. `código aberto`
- [Connectors (Agents)](https://go.mymarketing.click/mcpbr-connectors-agents) - Catálogo de servidores MCP remotos com OAuth, entre eles CNPJ e CEP e Hotmart, para o Claude, o Cursor e outros clientes. `do autor`

## Etiquetas

Cada item diz o que é. As etiquetas ao lado ajudam a escolher: oficial quando vem de quem define o padrão, código aberto quando o código está publicado, grátis ou pago pelo modelo de uso, API e SDK pelo jeito de integrar. Os itens com a etiqueta "do autor" são feitos por Ciro Cesar Maciel e seguem as mesmas regras de todos os outros.
