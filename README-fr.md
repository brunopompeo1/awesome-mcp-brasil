Pour ceux qui veulent que Claude, Cursor ou un autre agent d'IA consulte et utilise les services du Brésil via le Model Context Protocol. Chaque entrée est un serveur MCP existant, avec son code ou sa documentation publiés. Les projets communautaires ne sont pas officiels, sauf indication contraire dans l'étiquette.

## Données publiques et gouvernement

IBGE, Banco Central, Congrès et autres bases ouvertes.

- [bcb-br-mcp](https://go.mymarketing.click/mcpbr-bcb-br-mcp) - Données de la Banco Central pour agents : Selic, IPCA, change et PIB. `open source` `gratuit`
- [brasil-data-mcp](https://go.mymarketing.click/mcpbr-brasil-data-mcp) - Données publiques brésiliennes sur un seul serveur : CNPJ, CEP, banques, jours fériés, DDD, ISBN et indicateurs économiques. `open source` `gratuit`
- [cvm-mcp](https://go.mymarketing.click/mcpbr-cvm-mcp) - Un serveur MCP pour l'ensemble du dépôt de données ouvertes de la CVM. `open source` `gratuit`
- [ibge-br-mcp](https://go.mymarketing.click/mcpbr-ibge-br-mcp) - Les API de l'IBGE pour agents : données géographiques, démographiques et statistiques. `open source` `gratuit`
- [MCP Brasil](https://go.mymarketing.click/mcpbr-mcp-brasil) - Serveur MCP avec 70 API publiques brésiliennes. `open source` `gratuit`
- [mcp-dados-br](https://go.mymarketing.click/mcpbr-mcp-dados-br) - Données publiques de l'IBGE, de la Banco Central, de l'INMET, de la Câmara et du Senado. `open source` `gratuit`
- [mcp-senado](https://go.mymarketing.click/mcpbr-mcp-senado) - Les données ouvertes du Senado Federal pour agents : législation, sénateurs et votes. `open source` `gratuit`

## Étiquettes

Chaque entrée indique ce qu'elle est. Les étiquettes à côté aident à choisir : officiel quand elle vient de l'organisme qui définit le standard, open source quand le code est publié, gratuit ou payant selon le modèle d'utilisation, API et SDK selon la manière de l'intégrer. Les entrées avec l'étiquette « de l'auteur » sont faites par Ciro Cesar Maciel et suivent les mêmes règles que toutes les autres.
